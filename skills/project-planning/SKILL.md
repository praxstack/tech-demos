# Project planning (tech demos)

1. Restate the pick (tech name, bookmark URL, demo angle).
2. Write `apps/<kebab-slug>/PLAN.md` with: goal, MVP scope, non-goals, file layout, `bun` scripts, validation (screenshot + video).
3. Keep scope to a single-user MVP runnable with `bun install && bun run dev`.
4. Do not expand into other apps/ or create a new repo.
